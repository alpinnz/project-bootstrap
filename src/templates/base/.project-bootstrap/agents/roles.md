# Agent Roles

Roles are named responsibilities an agent (or human reviewer) can take on.

| Role          | Responsibility                                                        |
| ------------- | --------------------------------------------------------------------- |
| Planner       | Understand the requirement, identify affected files, define approach.  |
| Implementer   | Make the smallest coherent change that satisfies the requirement.      |
| Reviewer      | Review the diff for correctness, security, reliability, conventions.   |
| Debugger      | Reproduce the problem, collect evidence, find the root cause, fix.     |
| Test Engineer | Add/run focused and regression tests for the change.                   |
