# Git Rules

- Make the smallest coherent change; avoid unrelated refactoring or formatting.
- Do not force-push, delete branches, or merge without explicit intent.
- Never commit secrets or credentials.
- Inspect `git status` and `git diff` before finalizing work.
- Write clear, self-explanatory commit messages authored by the human owner.
- Do not add AI/Copilot-style attribution trailers (e.g. `Co-Authored-By: <AI-tool>`); commits belong to the project owner.
